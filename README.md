### About Me

I am a passionate software builder, IoT engineer, and low-level systems explorer. I love bridging the gap between high-level AI/Web software and low-level hardware. Whether it's training reinforcement learning agents, optimizing low-level ML frameworks in Rust, building smart IoT detectors, or crafting sleek web applications, I live for building things that push boundaries.

- I'm currently working on **Experimental-Rust-Machine-Learning-Optimization** and building AI microcontrollers.
- Special interests in **Machine Learning**, **IoT/Hardware**, and **High-Performance Systems Programming (Rust)**.
- Fun fact: Vibe-coded **abstracta.** in less than 10 minutes for the **Google Vibe Code Contest Indonesia** (May 2026)!
